# 餐饮 POS 系统 AI 研发闭环演示

一个可交互的单页演示，展示存量餐饮 POS 系统引入 AI 辅助研发后，一条门店反馈从进来到验收的完整闭环：

接收 → 分类 → 领域 Skill → 代码知识图谱定位 → 方案确认（人工审批）→ 修改 + 验证（三个 Runtime Worker）→ 人工验收

页面还演示了多任务并行时的任务锁、独立工作区，以及 Worker 中断后从状态机断点恢复。

## 说明

- 这是离线演示，没有接入大模型，各步骤的输出是预置的示例数据。
- 页面中的门店、人员、模块、文件名和代码片段均为虚构，不对应任何真实系统。
